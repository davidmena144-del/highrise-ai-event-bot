# تعليمات التثبيت والتشغيل

## المتطلبات

- Node.js 20 أو أحدث (تم التطوير والاختبار على Node 22).
- npm 10 أو أحدث.

## الخطوات

```bash
unzip highrise-ai-event-bot.zip
cd highrise-ai-event-bot
npm install        # ~200 حزمة، حوالي 200MB
npm run dev        # لوحة التحكم: http://localhost:5173
```

## أوامر أخرى

```bash
npm test           # تشغيل كل الاختبارات (37 اختبارًا)
npm run typecheck  # فحص TypeScript
npm run build      # بناء نسخة الإنتاج في dist/
npm run preview    # معاينة نسخة الإنتاج: http://localhost:4173
```

## أول استخدام

1. افتح "محاكاة اللعب التلقائي" واضغط "شغّل للآخر" لرؤية إيفنت كامل (7 أيام) يُدار تلقائيًا في ثوانٍ.
2. افتح "التقرير النهائي" لرؤية النتائج.
3. عدّل أرقام الإيفنت من "إعداد الإيفنت" بما يطابق اللي بتشوفه في اللعبة فعلًا (الأرقام الافتراضية موسومة بثقتها).
4. للإيفنت الحقيقي: بدّل الوضع من "الإعدادات" إلى "إيفنت حقيقي (إدخال يدوي)" واستخدم شاشة "متابعة الإيفنت الحقيقي".
