# بوت فعاليات هاي رايز الذكي — Highrise AI Event Bot

نظام متكامل لإدارة فعاليات (Events) لعبة Highrise: محرك فهم قواعد الإيفنت، محسّن طاقة ذكي، محاكي كامل، لاعب تلقائي، ولوحة تحكم عربية RTL.

## الحقيقة أولًا: إيه اللي شغال وإيه اللي لأ

| القدرة | الحالة |
|---|---|
| محاكاة كاملة لأي إيفنت | ✅ شغالة |
| لعب تلقائي جوه المحاكاة | ✅ شغال |
| محسّن طاقة (DP) مثبت صحته ضد خوارزمية مرجعية | ✅ شغال |
| متابعة إيفنت حقيقي بإدخال يدوي + توصيات | ✅ شغالة |
| تنفيذ إجراءات في حساب حقيقي | ❌ **مش متاحة رسميًا** — مفيش API رسمي بيسمح بده |
| قراءة الطاقة/المهام من حساب حقيقي | ❌ **مش متاحة رسميًا** |

التفاصيل والمصادر الرسمية في [docs/CAPABILITY_MATRIX.md](docs/CAPABILITY_MATRIX.md).

## التشغيل

```bash
npm install
npm run dev        # لوحة التحكم على http://localhost:5173
npm test           # كل الاختبارات
npm run typecheck  # فحص الأنواع
npm run build      # نسخة إنتاج
```

المتطلبات: Node.js 20+.

## المعمارية

```
src/core/
  types.ts       الأنواع + مستويات الثقة (VERIFIED / USER_PROVIDED / ESTIMATED / UNKNOWN)
  rules.ts       محرك ذكاء الإيفنت: كل قاعدة ليها مصدر وثقة
  energy.ts      مدير الطاقة: تجدد، حد أقصى، بطاريات، طاقة إضافية بانتهاء صلاحية
  optimizer.ts   محسّن ذكي: برمجة ديناميكية (وقت × طاقة) + مقارنة بالجشع + قاعدة البطاريات
  simulator.ts   محاكي: مهام، Party Time، مضاعفات، مكافآت عشوائية، انقطاعات شبكة، انتهاء إيفنت
  autoplayer.ts  اللاعب التلقائي: بدء/إيقاف مؤقت/استئناف/إيقاف فوري/استرداد جلسة/استرداد أخطاء
  session.ts     إدارة الجلسات: سجلات ولقطات استرداد، بعزل كامل بين المحاكاة والحقيقي
  report.ts      التقرير النهائي: تذاكر، كفاءة، درجة تحسين
  presets.ts     الإعدادات الافتراضية + مصفوفة القدرات الرسمية
  adapters/      محولات اللعبة: simulator (كامل) / manual (إدخال يدوي) / official (يفشل بأمان)
src/ui/          لوحة تحكم عربية RTL (React + Tailwind)، 9 شاشات
tests/           اختبارات: وحدة، تكامل، آلة حالات، عزل بيانات، واجهة
docs/            البحث، المعمارية، القيود، مصفوفة القدرات
```

## الأمان

- مفيش جمع كلمات مرور أبدًا.
- مفيش توكنات أو بيانات اعتماد متخزنة.
- مفيش تجاوز لأنظمة الحماية أو الكابتشا أو قيود المنصة.
- تخزين المحاكاة (`hreb:sim:*`) منفصل عن الجلسات الحقيقية (`hreb:real:*`).
- زرار **إيقاف فوري** ظاهر في كل الشاشات.

## المصادر

- آليات الإيفنتات المؤكدة: مقالات دعم Highrise الرسمية (الروابط في docs/RESEARCH.md).
- الأرقام التقديرية (فترة التجدد ≈ 4 دقائق، Party Time كل ≈ 6 ساعات): أدلة مجتمع، موسومة ESTIMATED في الكود والواجهة.
